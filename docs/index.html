Analyse bulk RNA-seq and microarray studies through a guided desktop workflow. Start with the data you have, follow the steps that apply, and learn what each choice changes.

Walk through my analysis Install and prepare

Output changes in version 0.31.0

This release changes several recorded outputs, so the same input can give a different result than it did in 0.30.1: the alternative count engines now write the identifier, PCA and effect-size columns the DESeq2 route already wrote, the covariate screen uses a sample-size-aware rule, and two checks report more. Re-run anything you intend to publish, and read the version notices first.

What the application does#

The interface configures a Snakemake workflow for read processing, gene quantification, differential expression and applicable downstream interpretation. You can also enter later with counts, microarray intensities or a completed differential-expression table. A shortcut skips the earlier work; it does not reconstruct missing measurements.

Choose your starting point#

Use the five input routes to identify the correct format. Then prepare your sample sheet, reference and comparison. The interactive walkthrough keeps those decisions in order.

What it is#

A desktop interface for a transparent bulk-expression workflow, with saved settings, route-specific checks and inspectable result files. It supports both guided operation and command-line execution.

What it is not#

It is not a single-cell workflow, a clinical diagnostic system or an automatic explanation of biological causation. A successful run means computations completed; its study design, quality checks and interpretation still require review.

Processing is local, but setup, public-data retrieval and online annotation/network services need connectivity. Local processing does not mean every enabled feature is offline. See service connectivity.

Read at your level#

Keep the main steps open for a first analysis. Expand Advanced sections for exact settings and implementation limits. Click a glossary term such as Contrast for a short definition. Illustrative examples explain choices and are not measured results.
