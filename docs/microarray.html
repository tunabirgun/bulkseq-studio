How-to guides

Microarray input

Bring GEO or local expression intensities into the limma route.

On this page
  • 1. Choose a source
  • 2. Set processing deliberately
  • 3. Review sample groups and identifiers
  • 4. Run and review array-specific checks

Before you start, identify the array platform and whether intensities have already been normalized and log2 transformed. RNA-seq counts and microarray intensities need different input routes.

1. Choose a source#

On Add data → Microarray, enter a GEO GSE accession or choose Import microarray matrix for a local table. An RNA-seq GEO series belongs on the public-read route and is redirected to SRA.

Check before proceeding

For a local file, use a gene-by-sample TSV or CSV with gene IDs/symbols in the first column and already-normalized log2 intensities in sample columns.

2. Set processing deliberately#

SettingWhat it changesWhen to change it / example
GEO series matrix (default)Uses the submitter-normalized matrix rather than reprocessing raw arrays.Choose when the deposited processing matches your planned analysis; read the GEO processing description.
Affymetrix raw CEL → RMAReprocesses supported raw Affymetrix arrays with RMA.Use when intentionally re-normalizing available CEL files; this is not a generic raw-format importer for every array platform.
Log2 transform: auto / force / offControls whether intensities are transformed. Double transformation distorts their scale.Illustration: an intensity 256 becomes 8 after log2. If values are already log2 intensities, another log2 is not the same analysis.
Local matrixUses your processed intensities without a GEO download.Confirm preprocessing with whoever supplied the matrix; a plausible-looking number range is not full provenance.

3. Review sample groups and identifiers#

Fetched GEO arrays map probes to gene symbols; the platform accession is recorded. For a local gene matrix, ensure identifiers match the selected organism. Review condition labels and build the comparison on Samples and Analysis settings.

Check before proceeding

Use dot decimal separators. Blank or NA can represent missing values; text placeholders and comma-decimal numbers are refused rather than silently converted.

New in 0.32.0

GEO annotation is parsed across every candidate and repeated row for each probe. A probe enters MaxMean collapse when the combined known candidates identify exactly one distinct gene; ambiguous, unknown and missing-annotation probes are excluded and counted by check 12. The probe-map table retains escaped raw annotation, sorted candidates and the resolution class. Local gene-level matrices keep their supplied identifiers. Synthetic tests establish this mapping contract; no GEO study or published microarray benchmark has been rerun under 0.32.0.

4. Run and review array-specific checks#

The route fits limma and writes a common differential-expression table schema. That filename/schema does not mean DESeq2 was fitted. Inspect normalization and probe-mapping checks before interpreting downstream figures or enrichment. There is no FASTQ, alignment or RNA-seq read-count QC for this route.

Advanced: design limits in the published baseline

Microarray limma supports the documented additive design route. Interaction and nesting operators are rejected in the published baseline; do not assume the same design capabilities as DESeq2. See advanced design.
