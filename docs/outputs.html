Inspect the complete result first#

Open the main report and read the recorded outcome and attention items before interpreting its findings. Then inspect the full differential-expression table and its recorded comparison, followed by the applicable figures, enrichment and networks. A selected gene list is a filtered view of the result.

Missing, unreadable or malformed evidence is labelled unavailable; it is not a zero-result finding. Reports retain complete recorded check messages and link the output files present in the project. Their embedded view opens as one HTML file, but links to complete tables and other saved outputs require the accompanying project files.

Missing adjusted p-values are not evidence of no effect. A network association is not necessarily direct physical binding, and enrichment does not establish pathway activation.

Simulated RNA-seq, eight samples. Colors are clipped at the selected limit.

How to read this example

These rlog expression values come from a DESeq2 fit to simulated counts. A row z-score subtracts that gene’s mean and divides by its sample standard deviation across the eight samples. Equal colors across genes do not imply equal expression.

Rows stay in adjusted-p order so you can compare color limits. This example does not demonstrate clustering. The teaching slider spans 1–3 for legibility; BulkSeq accepts color limits from 0.1 to 10. The application clusters its clipped row-score matrix, so its color-limit setting can also affect the clustering. Changing the gene count here changes the displayed subset, not the fitted differential-expression results.

What the network shows

This curated set of 12 proteins is a public teaching example, not a result from the simulated expression data. Nodes have equal size and fixed positions. Distances have no biological meaning. Isolated nodes remain visible and count as connected components.

Scores are displayed on the application’s 0–1000 scale. An edge can represent functional evidence and does not establish direct physical binding or an interaction measured in your samples. The snapshot includes only scores of 400 or more; the application accepts cutoffs from 1 to 1000. Changing the cutoff filters this cached network; it does not change the source evidence.

Two meta-analysis summaries#

The combined-p result summarizes evidence from separate studies. The pooled-effect result estimates an average log2 fold change under its model. Read both with the per-study effects and the eligibility record; they are not interchangeable tests. Explore a pooled effect in the forest plot.

FieldInterpretation
combined_padjBH-adjusted combined p-value within the matching, nonzero-direction family. Discordant or zero-effect rows have no adjusted value in this family.
meta_sigMatching nonzero directions and combined adjusted p below the run’s alpha. This rule does not require each study to be significant or impose the ordinary fold-change reporting threshold.
rem_log2FC and confidence limitsPooled unshrunken effect estimate and its interval; inspect the individual study estimates too.
rem_padjAdjusted pooled-effect test. Since v0.34.0, BH covers all estimable pooled tests, including discordant and zero-direction rows.
n_studies_sigNumber of studies below their adjusted-p threshold; this count does not apply the per-study fold-change screen.
Heterogeneity, filtering and status

With two studies, BulkSeq uses a common-effect fit and deliberately leaves tau2, I2 and QEp unreported. Missing heterogeneity fields are not estimates of zero heterogeneity. With three or more studies, the pooled fit uses DerSimonian–Laird random effects. P-values and intervals use z-based Wald inference; treat pooled findings as exploratory when few studies are available.

Inspect meta_eligibility.json for excluded studies, post-filter gene sets, the shared identifier intersection, missing-statistic losses and pooled-model failures. Unsupported designs, fewer than two eligible studies, or no shared complete-case genes fail. A nonempty result with no meta-DEGs receives REVIEW_REQUIRED. A status-only graphic shown for empty or unavailable results or two-study heterogeneity is not biological evidence. Check 18 distinguishes cross-study enrichment execution failure from a completed test with no retained terms. Inference is limited to shared complete-case genes; exclusion from this set does not establish absence of an effect.

Results from older releases

Recompute meta-analysis results made before v0.34.0 before interpreting rem_padj. The correction concerns the pooled-effect adjustment family. It did not change the matching-sign combined-p adjustment or meta_sig definition. Preserve the earlier output and its recorded version when comparing runs.

Figure settings, reports and file reference

Before you start, confirm the input route, comparison direction and completed checks. A file named deseq2 or a shared results schema does not establish which statistical engine ran.

1. Open the result tables#

Open Figures and tables and inspect the full differential-expression table before selected gene lists. Read log2FoldChange and adjusted p-values alongside the documented direction. The up/down lists apply both alpha and |log2FC| filters.

Warning

Keep missing adjusted p-values distinct from significant or unchanged genes. Non-significance is not an equivalence claim.

2. Read each figure for its intended purpose#

A volcano combines effect size and adjusted-p evidence. The published baseline uses unshrunken log2 fold change on its x axis. PCA, sample distance and correlation summarize sample structure when an expression matrix exists; they do not independently test the treatment contrast. Heatmap row z-scores show relative within-gene patterns, not absolute expression differences between genes.

An MA plot combines mean expression and effect size; the required mean must exist. RNA-seq-specific dispersion, Cook’s-distance and library diagnostics do not apply to every route. Imported-results projects cannot supply matrix-based PCA or heatmaps.

Leave Font family at (default serif) to request Times New Roman from the R renderer. If that family is unavailable, the renderer logs the named installed serif it uses instead; if no serif fallback exists, figure rendering stops. A family selected explicitly in the GUI should also be available to the analysis backend. Inspect the exported PNG and SVG to confirm the actual typeface. Use the Style tab, click Regenerate figures, then Refresh figures. Vector (SVG) previews a scalable export. Figure regeneration does not rerun alignment or the primary DE model, although choices such as the PCA feature count change the displayed derived calculation.

4. Generate and inspect reports#

On Reports, open the stored main results report when it exists; Generate Reports is available for a project without one. A stored cross-study report has its own direct action, even when the current option is off. The main report first presents the recorded check outcome and attention items, followed by results and supporting evidence. Main and cross-study reports provide labelled section navigation, a skip link, keyboard access to wide tables and complete recorded check messages. An output index links saved files that exist in the project; those links require the accompanying project files. Sortable tables, definitions shown on hover, focus or tap, and a figure viewer with Fit, Actual size and percentage zoom support inspection. Missing, unreadable or malformed tables are labelled unavailable rather than counted as zero results. Sorting and zooming change the display only; the saved tables hold the complete results.

Check

Read the Run provenance table under Software & provenance: it names the application and workflow versions that executed, the workflow digest and copy time, the installed environment specification, the environment lock hash and the workflow commit, and states plainly when one of them was not recorded. The identifier-mapping evidence lines the report quotes under enrichment are the same lines results/enrichment/enrichment_summary.txt and the run summary carry, so a mapping exclusion cannot appear in one and be missing from the other. Inspect the exported file before sharing; metadata and sample labels can be sensitive.

Advanced: engine parity, ranking and provenance

The count engines share one results schema but not one feature set. ncbi_geneid, pca_coordinates.csv with its covariate screen, and the padj_lfc_ge_threshold companion column are written by DESeq2, edgeR and limma-voom alike; the companion column uses each method’s own interval test (DESeq2 greaterAbs, edgeR glmTreat, limma and limma-voom treat) at the configured fold-change threshold, is informational and never decides which genes are called. lfcSE carries a value on DESeq2, limma-voom and microarray limma; edgeR quasi-likelihood reports no per-gene standard error and leaves the column empty. unchanged_genes.csv and check 13 are written on the DESeq2 route only. The recorded fold-change threshold test is named in results/reports/sessionInfo.txt.

Locally fitted models export a signed model statistic for preranked use, with a documented fallback when no finite statistic is available. Imported results use confirmed log2FoldChange. Tools/references and design exports describe the route that actually ran, including installed environment specification and input provenance rather than attributing inactive defaults to the analysis. The matrix-based Wilcoxon sensitivity check is diagnostic only: when groups are small, exact p-values are discrete and power is limited, so its warning supports rank-concordance review and does not change the differential-expression calls.

New in 0.32.0

Sortable report columns retain table headers for assistive technology. Select the labelled header button with a mouse, Enter or Space to cycle ascending, descending and the source order. Sorting changes only this report view. Machine, full-configuration and imported-results provenance tables expose their left cells as row headers.
